# Amazon Brazil E-commerce Analysis | SQL

## Project Overview
Analyzed Brazilian e-commerce data using PostgreSQL to explore sales performance, customer purchasing patterns, payment preferences, and product trends.

## Tools & Technologies
- PostgreSQL
- SQL
- pgAdmin

## Database Tables
- Customers
- Orders
- Payments
- Sellers
- Products
- Order Items

## SQL Concepts Used
- Aggregate Functions
- Joins
- Subqueries
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- RANK() and LAG()
- Cumulative Sales Analysis

## Analysis Performed

### Analysis I
- Average payment by payment type
- Payment distribution
- Product price analysis
- Monthly sales analysis
- Product category price differences

### Analysis II
- Order value segmentation
- Product category pricing
- Repeat customer identification
- Customer segmentation
- Top revenue-generating categories

### Analysis III
- Seasonal sales analysis
- Product quantity analysis
- Monthly revenue trends
- Customer segmentation
- Top 20 customers by average order value
- Cumulative monthly sales
- Month-over-month payment analysis

## Project File
`AmazonSQLanalysis.sql` – SQL queries covering database creation and business analysis.

## Key Learnings
Practiced SQL querying, data aggregation, joins, customer segmentation, CTEs, subqueries, and advanced window functions.
